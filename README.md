# FemeGus Caption Generator — downloads

Free, local caption generator for After Effects (word-timed, editable text layers; English and Hinglish). Everything runs on your own computer.

**Latest version: 0.9.5**

## Install
1. Download [`femegus-caption-gen-0.9.5.zip`](releases/0.9.5/femegus-caption-gen-0.9.5.zip) (use the *Download raw file* button) and unzip it to a folder you will keep, e.g. `C:\FemeGus`.
2. Double-click **`Install-FemeGus.cmd`** and answer the questions. It sets everything up (needs Python 3.10–3.12 and an internet connection for the one-time downloads).
3. Follow `docs\FIRST_RUN.md` (two short After Effects steps).

## Updates
Inside the app: section 10 ▸ **Updates**. The app reads `latest.json` from this repository; it never sends anything about you or your footage.
Tested with After Effects 2025 (25.2) on Windows. Other versions are not supported yet.
